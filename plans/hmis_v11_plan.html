🔌 Module Interface Chuẩn (API Contract)

Mỗi module bắt buộc phải implement các endpoint sau:

GET /healthKiểm tra trạng thái module (return {status: "up", version: "1.0.0"})
GET /infoMetadata: name, version, language, dependencies, apis, events
POST /webhook/{event}Nhận event từ Event Bus (Kafka / Webhook)
GET /openapi.jsonOpenAPI 3.0 specification cho module
POST /config/reloadHot-reload configuration (không restart module)

Lifecycle Hooks: on_install() → on_enable() → [running] → on_disable() → on_uninstall()
