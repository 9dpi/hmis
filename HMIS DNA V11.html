Kiến trúc Module & Khả năng Mở rộng

"Hệ thống cần module hóa hoàn toàn (IoT, AI, EHR, PACS là các module độc lập 'cắm vào'), API chuẩn hóa, và vận hành như một Hệ điều hành y tế."

Chuẩn Module Interface (Bắt buộc)

  • Lifecycle Hooks: on_install(), on_enable(), on_disable(), on_uninstall()
  • API Contract: OpenAPI/Swagger, Versioning /api/v1/*
  • Database Isolation: Schema prefix module_name_
  • Event System: Subscribe/Publish qua Kafka bus

Chiến lược "2 Tốc độ" (Hybrid)

JAVA
Core Platform (Spring Boot)

Đảm nhận: Auth, RBAC, Billing, Hồ sơ lõi (EMPI). Ưu tiên: Ổn định, bảo mật cao.

PY
Feature Modules (FastAPI)

Đảm nhận: AI ( TensorFlow/PyTorch), IoT. Ưu tiên: Linh hoạt, AI-ready.
